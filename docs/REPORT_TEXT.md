# КР 1. Разработка консольной информационной системы на Java

## Название
Информационная система сервиса обслуживания аквариумов «Заявка на обслуживание аквариума».

## Цель
Разработать консольную информационную систему для хранения, обработки и анализа заявок на обслуживание аквариумов с использованием Java, ООП, JDBC и PostgreSQL.

## Основные сущности
1. Клиент.
2. Заявка на обслуживание аквариума.

Клиент может иметь несколько заявок. Связь реализована внешним ключом `service_requests.client_id`.

## Основные операции
Для заявок реализованы создание, просмотр всех записей, получение по ID, изменение, удаление, поиск, фильтрация и сортировка.

## Архитектура
`Console UI -> Service -> Repository / JDBC -> PostgreSQL`.

## Бизнес-правила
Система проверяет существование клиента, обязательность основных полей, диапазон приоритета, неотрицательность стоимости, корректность статуса и допустимость переходов статуса.

## Экспорт
Основные данные можно экспортировать в Excel `.xlsx`; дополнительно реализован CSV.

## Итог
Получено консольное приложение, соответствующее требованиям КР1 и пригодное для дальнейшего расширения в следующих контрольных работах.
