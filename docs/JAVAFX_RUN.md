# JavaFX-клиент

Клиент КР №2 работает напрямую с PostgreSQL через существующие `Repository` и `Service` слои. Основная сущность интерфейса — заявка на обслуживание аквариума.

## Запуск

Установите Docker Desktop с Docker Compose, JDK 17+ и Maven. Создайте `.env` на основе `.env.example`, задайте свой пароль и запустите PostgreSQL:

```powershell
Copy-Item .env.example .env
# Измените POSTGRES_PASSWORD в .env перед запуском
docker compose up -d --wait
```

При первом старте Compose создаёт базу `aquarium_service` и загружает схему и демонстрационные записи из `sql/schema.sql`. Данные хранятся в именованном Docker volume. Для остановки контейнера выполните `docker compose down`; данные при этом сохраняются.

Если база уже была создана до исправления кодировки seed-данных, примените одноразовое исправление к демонстрационным строкам:

```powershell
Get-Content -Raw -Encoding utf8 sql/fix_seed_encoding.sql | docker exec -i aquarium-postgres psql -U postgres -d aquarium_service -v ON_ERROR_STOP=1
```

Скрипт затрагивает только демонстрационные записи с ID клиентов 1–5 и заявок 1–10, в которых обнаружен повреждённый текст.

Клиент автоматически читает `POSTGRES_USER`, `POSTGRES_PASSWORD` и `POSTGRES_PORT` из `.env`. При необходимости параметры можно переопределить переменными `AQUARIUM_DB_USER`, `AQUARIUM_DB_PASSWORD`, `AQUARIUM_DB_URL`. Запустите клиент:

```powershell
mvn javafx:run
```

JavaFX-клиент остаётся настольным приложением и запускается на компьютере. Docker здесь запускает PostgreSQL, к которому клиент обращается через опубликованный порт `5433`.

`mvn exec:java` по-прежнему запускает консольный клиент КР №1. `mvn javafx:run` запускает настольное приложение.

## Возможности

- таблица заявок с сортировкой по нажатию на заголовок;
- поиск по клиенту, описанию, услуге и ID;
- фильтры по статусу, типу аквариума и минимальному приоритету;
- создание, редактирование и удаление заявок с подтверждением;
- отдельное окно для создания, редактирования и удаления клиентов, аквариумов и рыб;
- проверка полей и существования клиента в сервисном слое, включая ограничения перехода статусов;
- статистика: число заявок, активные, высокий приоритет, просроченные, выполненная выручка и средняя стоимость;
- экспорт текущей отфильтрованной таблицы в CSV через диалог выбора файла.

В диалоге заявки плановая дата вводится в формате `yyyy-MM-ddTHH:mm`. Клиент для заявки выбирается из записей таблицы `clients`.

Клиентов, аквариумы и рыб создавайте через кнопку **«Клиенты и аквариумы»** внизу главного окна. Сначала добавьте клиента, затем на вкладке «Аквариумы» создайте аквариум для него; после этого на вкладке «Рыбы» можно добавить виды и количество рыб. Удаление клиента или аквариума показывает предупреждение о каскадном удалении связанных данных.
